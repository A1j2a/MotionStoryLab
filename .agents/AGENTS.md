# Coding Rules

- Always search the repository before implementing.
- Always reuse existing code before creating new code.
- Reuse existing hooks and components.
- Never duplicate business logic.
- Prefer existing project utilities.
- Prefer React Native APIs over new libraries.
- Don't install new npm packages unless asked.
- Don't create new files/folders unless absolutely necessary.
- Don't change formatting of unrelated code.
- Keep diffs as small as possible.
- Only modify affected files and fix only the requested issue.
- Don't refactor unrelated files.
- Prefer readability over clever one-liners.
- Follow existing project architecture (Lerna monorepo, Appmaker SDK block/page/filter/action patterns).
- After coding, explain what changed and why.
